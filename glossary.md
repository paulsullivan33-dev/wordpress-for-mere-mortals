# Glossary

- **Administrator** — the all-powerful
  WordPress role: settings, users,
  themes, plugins, everything
  (chapter 10).
- **Akismet** — the bundled anti-spam
  plugin; a client for a hosted service,
  useless until it has an API key
  (chapter 9).
- **Application password** — a separate,
  revocable password for one user and
  one program, used by the REST API and
  other non-browser clients; distinct
  from the login password (chapter 12).
- **Block theme** — a modern theme whose
  templates are assembled from blocks in
  the Site Editor, styled largely
  through `theme.json` (chapter 8).
- **Contributor** — a role that can
  write and edit its own drafts but
  cannot publish (chapter 10).
- **Cookie jar** — where a program
  (here, `curl`) stores a site's cookies
  between requests, standing in for a
  browser (chapter 6).
- **Core** — WordPress itself: the
  downloaded PHP files, identical on
  every site of the same version, and
  verifiable file by file (chapter 2).
- **Dashboard** — the administration
  screens under `/wp-admin/`, reached by
  logging in (chapter 6).
- **Draft** — a post or page with the
  status `draft`: present for staff,
  absent for readers, front page and API
  alike (chapter 7).
- **GPL** — the free-software licence
  WordPress is published under.
- **MariaDB** — the community fork of
  MySQL; one of the two databases
  WordPress officially supports, and
  this lab's choice (chapter 3).
- **Multisite** — one WordPress install
  hosting many sites; a mode of its
  own, documented-only here
  (chapter 16).
- **Permalink** — the permanent address
  of a post or page, and the *structure*
  setting that shapes all of them at
  once (chapter 7).
- **Phar** — a PHP archive: a whole PHP
  program packaged as one file — how
  WP-CLI is distributed (chapter 11).
- **Plugin** — extra code that hooks
  into the core to add abilities; runs
  with the site's full privileges
  (chapter 9).
- **Post / page** — the two everyday
  kinds of writing: dated and listed
  versus standing alone at its own
  address (chapter 7).
- **REST API** — the machine-facing
  interface under `/wp-json/`, serving
  the site's content as JSON
  (chapter 12).
- **Role** — a named bundle of
  capabilities assigned to a user
  account (chapter 10).
- **Salts** — the eight secret random
  strings in `wp-config.php` that sign
  login cookies (chapter 4).
- **Slug** — the readable tail of an
  address, made from the title, e.g.
  `village-fete-returns-to-the-green-this-saturday`
  (chapter 7).
- **Socket** — a file through which
  programs on the same machine talk;
  the lab's MariaDB listens on one
  instead of a network port
  (chapter 3).
- **Theme** — the presentation layer:
  templates and styles deciding how
  content looks, never what it says
  (chapter 8).
- **wp-config.php** — the one config
  file you write: database credentials
  and the salts (chapter 4).
- **wp-content/** — the folder that is
  truly the site's own: themes, plugins
  and uploads; untouched by core updates
  (chapter 2).
- **WP-CLI** — the official command-line
  companion to WordPress (chapter 11).
- **wordpress.com** — Automattic's hosted
  service running the WordPress
  software for a subscription; not the
  software itself (chapter 1).
