# What WordPress Is

**WordPress** is a publishing system:
software that lives on a server, holds
your writing in a database, and builds
each web page at the moment a visitor
asks for it. You write in a browser,
through forms and an editor; your
readers see finished pages. Between the
two sits the machinery this guide takes
apart — a program in PHP, a database, a
theme that decides how things look, and
plugins that bolt on extra abilities.

It began in 2003 as a tool for blogs —
dated posts in a stream, newest first.
It is still excellent at that, but the
same machinery now runs club sites,
small business pages, portfolios, shops
and a good slice of the world's news.
Estimates vary, but something like two
in five websites run on it. That
popularity is itself a feature: almost
any problem you can have, someone has
had before, in public, with an answer.

## The deal WordPress makes with you

WordPress itself is **free software** —
free to download, free to run, licensed
under the GPL so you may read and change
its code. What it asks in return is
responsibility. A self-hosted WordPress
site is *yours* in every sense: yours to
design, and yours to update, back up,
and keep secure. Nobody else's
operations team is watching it at 3 a.m.
Chapters 13 and 16 take that seriously;
a WordPress site that is never updated
is the internet's most common sad story.

Be clear about the two things called
WordPress, because confusing them wastes
more beginner hours than any other
single mistake:

- **WordPress the software** (from
  wordpress.org) is what this guide
  installs. It runs on a server you
  provide.
- **wordpress.com** is a hosting company
  that runs the software for you, for a
  subscription, with limits that loosen
  as you pay more. It is a fine service
  and a different thing.

## What it is not

It is not a **page builder** first,
though plugins can turn it into one; the
core idea is structured writing — posts,
pages, titles, dates, authors — poured
into a theme. It is not a static site:
nothing is a finished HTML file until a
visitor asks, which is why it needs a
running program and a live database
behind it (chapter 2). And it is not a
walled garden: your words sit in an
ordinary database you can export any
time — chapter 13 exports one — which
matters if you ever want to leave.

## What the lab built

So the ideas stay concrete, this guide's
lab installed the genuine current
release — WordPress 7.1.4 — and built a
fictional village newsletter, *The
Millbrook Weekly*, with an invented
editor and invented readers. Everything
in the transcripts was done to that
site: real posts published, a real
comment held and approved, a real theme
switched. The village is made up; the
software's behaviour is not.
